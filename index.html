Full Project Seal QC Checklist v10 — every section must pass before submitting.

0. Metadata Read Gate

  1. metadata.md exists beside the task files or in the task root
  2. Task title or task id is present
  3. Prompt or question text is present
  4. Expected answer or target answer field is present
  5. Required source URLs or source constraints are present
  6. Any forbidden source rules are present
  7. Any submission requirements are present
  8. The QC tester has read the full metadata file before running the checklist

A. Ground Rules

  1. Factual questions only
  2. Short, specific answers
  3. Find the answer first
  4. Accessible sources, no paywalls or broken links
  5. No plagiarism
  6. Be honest in Test Evidence
  7. No yes/no, true/false, or binary questions
  8. No questions without a defensible answer
  9. One submission at a time

B. Prompt Rules — 8 Checks

  1. Requires verification through web based research through URLs. Cannot be answered from common knowledge or arithmetic alone
  2. No shortcuts. The answer is not derivable from the wording itself
  3. No external references. Fully self contained, no tables, images, attachments, or prior conversation
  4. Clear grammatical attachment. Every clause and pronoun attaches to exactly one referent
  5. Question is specific. Delete the answer mentally, the remaining constraints point to exactly one entity
  6. Claims are factual. Every statement in the question is true, no false premises
  7. Unique obvious answer. After real research, one answer clearly dominates, and it does not depend on the date you ask
  8. Answer is correct. Verified against a primary source, traced past any encyclopedia to the source it cites

C. Write the Answer

  1. Answer is atomic: a single word, number, date, name, or short phrase
  2. Only one defensible answer exists, triple checked against the live source
  3. No "the answer is", no explanation, no hedging, no alternates in the answer field
  4. Not a yes/no, true/false, or pick between two question
  5. A primary source is open right now that unambiguously proves the answer

D. Verification Sources

  1. Every URL is stable, the exact fact will still live at that exact URL 5 years from now
  2. Every URL is freely accessible, no paywalls, no logins, no downloads required
  3. Every URL is from a reputable publisher: a specific .gov page, SEC filing, dated news article, peer reviewed source. Wikipedia is blocked on this project, never in the list
  4. No invalid sources: no search results pages, social media, YouTube or Vimeo, Google Docs, Grokpedia, or Wayback snapshots
  5. No homepages, live dashboards, leaderboards, stock tickers, or latest, current, today pages that auto update
  6. Every intermediate and final answer is text living in the page's HTML, highlightable or Ctrl+F findable
  7. Every URL was opened again right before submitting, still live, still showing the fact cited

E. Golden Trajectory

  1. Every step names how I got to the URL: the search query, links clicked, or navigation path
  2. Nothing in the path, search, link text, or navigation, gives away the answer
  3. Every constraint in the prompt has its own step tied to a valid URL and a defensible intermediate answer
  4. Every step narrows the field and explains why that constraint moves closer to the answer
  5. Each fact includes the exact location on the page: PDF page, paragraph, row and column labels
  6. Every URL loads in an incognito tab, no login, paywall, or 404, and the fact is highlightable in the page's HTML
  7. Every fact matches the live source exactly, not memory, not paraphrase
  8. The last step spells out why the final answer is NOT ambiguous and why it is defensible

F. ChatGPT Setup

  1. Own ChatGPT account with ChatGPT 5.5 Pro access
  2. Model GPT 5.5 Pro, Thinking effort Extended
  3. Memory OFF, verified in Settings before running
  4. Fresh chat every time, no reused context
  5. Prompt pasted as is, no extra context, hints, or "please show your work"

G. Record Model Response

  1. Full model response pasted verbatim, not just the final answer, no edits or summary
  2. ChatGPT share link grabbed and pasted in the form
  3. Chat left live, not deleted after submitting
  4. Both fields filled, full response plus share link. Missing either is a rejection

H. Failure Checks

  1. The model reached an incorrect final answer, not a correct answer, not a correct refusal, not a non answer
  2. The failure holds consistently across runs, not once by luck
  3. The wrongness is substantive: not formatting or rounding, not abbreviations or stylistic variation, not the right answer with sloppy reasoning
  4. The failure is a genuine model limitation, not caused by an ambiguous or underspecified prompt
  5. Response Failure Justification written in 2 to 4 sentences, naming the correct answer and where the model went off track, never N/A

I. Pre-Submit — 18 Rejection Reasons

  1. Prompt has exactly one defensible answer, ambiguity test run
  2. Not a yes/no or true/false question
  3. No hints, names, or clues about which source to use
  4. Cannot be solved from general knowledge or arithmetic alone
  5. Answer will still be correct 5 years from now
  6. No "as of today", "currently", "latest", or other floating time words
  7. No process instructions like "then", "after that", "first do X"
  8. Constraints actually narrow to one answer, not vague adjectives
  9. At least 3 URLs, each from a genuinely different domain
  10. Every URL loads clean in incognito, no paywall, login, or 404
  11. URLs are timeless too, no live dashboards, leaderboards, or homepages that update
  12. URL list matches the golden trajectory one to one
  13. Nothing in the path, search, click, or navigation, gives away the answer
  14. Every step names how I got there, the URL, and exactly where on the page the fact lives
  15. Answer field is atomic, a single word, number, date, name, or short phrase
  16. No lead in like "the answer is" in the answer field
  17. Full model response pasted verbatim AND the ChatGPT share link included
  18. Every fact pulled matches exactly what is on the live page, not memory, not paraphrase

J. Final Pre-Submit Scan

  1. Answer is atomic
  2. Only one defensible answer exists
  3. Requires reading at least 3 valid URLs from different domains
  4. Facts converge or chain to the answer
  5. Verified the answer myself before submitting
  6. Did not hint at or name a source that would cut the required valid URLs below 3
  7. Did not write a yes/no question
  8. Did not rely on math the model can do without browsing
  9. Did not use vague or time sensitive words
  10. Did not make it so obscure the model just refuses

K. QC Outcome Rule

  1. PASS: Every checklist item above is true after reading metadata.md
  2. FAIL: One or more checklist items are false and the task must be fixed
  3. BLOCKED: metadata.md is missing, incomplete, unreadable, or conflicts with the task files

Do not submit a task until the outcome is PASS.
