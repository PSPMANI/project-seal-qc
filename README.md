# Project Seal — QC Checker

Automated quality control checker for Project Seal task submissions. Paste your `metadata.md` content and get instant checks against the full QC checklist.

**Live site:** [https://pspmani.github.io/project-seal-qc](https://pspmani.github.io/project-seal-qc)

## Features

- 30+ automated checks across 8 sections (Metadata Gate, Prompt Rules, Answer Quality, Sources, Golden Trajectory, Model Response, Failure Checks, Cross-checks)
- Instant PASS / FAIL / BLOCKED verdict
- Runs entirely in-browser — no data is uploaded
- Dark mode support
- Copy results to clipboard
